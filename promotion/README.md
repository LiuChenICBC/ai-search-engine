## 推广策略

### 第一阶段：立即执行（1-2天）

1. **GitHub 仓库优化**
   - 添加仓库描述
   - 添加 Topics
   - 添加徽章到 README

2. **中文社区推广**
   - V2EX 发帖
   - 知乎回答/发帖
   - 掘金发布文章

### 第二阶段：一周内

1. **英文社区推广**
   - Reddit r/selfhosted 发帖
   - Reddit r/Python 发帖
   - Hacker News Show HN

2. **技术博客**
   - 发布中文博客到掘金/CSDN

### 第三阶段：持续进行

1. **社交媒体**
   - Twitter/X 定期发布更新
   - 回复社区反馈

2. **社区互动**
   - 回答相关问题
   - 参与讨论

## 使用方法

1. 打开对应文件
2. 复制文案内容
3. 根据实际情况微调
4. 发布到对应平台

- 避免过度推广，保持真诚
